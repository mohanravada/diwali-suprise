DIWALI SURPRISE WEBSITE

Files:
- index.html: website source code
- diwali-opening.mp4: opening Diwali video
- references/mohan-character-reference.png: Mohan anime character sheet
- references/pavani-character-reference.png: Pavani anime character sheet

To run:
1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click index.html and choose Open with Live Server.

Secret code: 1314316

Final eye reveal image:
The website expects a file named pavani-eyes.png beside index.html. Add the selected cropped eye image with that exact filename. The character sheets are kept in references/ for use when creating the final anime animation assets.

Note: The college characters in this version are CSS silhouette prototypes. The anime character sheets are included as visual references, not yet rendered into the animation.
